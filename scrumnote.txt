Introduction:
This is an AI-powered customer support ticket intelligence system designed for 
consumer electronics enterprises. It automates ticket classification, priority 
prediction, Top-3 similar historical ticket retrieval, and dynamic department 
routing using Natural Language Processing and Machine Learning to reduce 
response times and eliminate manual triage errors.

Objectives:
• Automate end-to-end customer support ticket triage and routing.
• Classify customer complaints into predefined categories using Logistic Regression.
• Predict the priority level (Low, Medium, High, Critical) for incoming tickets.
• Retrieve Top-3 similar historical tickets using TF-IDF and Cosine Similarity.
• Provide AI-based historical solution context to assist support staff.
• Implement Role-Based Access Control (Customer, Agent, Admin) with security gatekeeping.
• Reduce manual effort and improve customer satisfaction (CSAT) through faster support.

#Existing System:
Existing customer support operations rely on manual triage by human agents or rigid 
rule-based pattern matchers that are slow, error-prone, and lack semantic understanding.

System                  | Description                                  | Limitation
------------------------+----------------------------------------------+--------------------------------------
Manual Support Triage   | Human agents read and route tickets manually.| Slow response time, high misrouting.
Rule-Based Regex Routers| Uses rigid keyword matching rules.           | Lacks semantic context; breaks easily.
Generic Helpdesk Forms  | Standard web forms without AI intelligence.  | No automated priority/category triage.
Keyword Search Systems  | Basic text matching for past resolutions.    | Low relevance, zero vector similarity.
Static Support Queues   | Monolithic queues without role isolation.    | No fraud escalation desk or SLA tracking.


#Proposed System:
It proposes a cost-effective, intelligent AI support ticket system that combines real-time 
NLP categorization, machine learning priority prediction, Top-3 cosine similarity retrieval, 
and automated multi-department routing with a modern web dashboard.

> AI Classification & Retrieval Mappings
Input Pattern / Issue          | Target Action / Department | AI Inference Method
-------------------------------+----------------------------+--------------------------------------
Error, crash, kernel, 502, API | Technical Support          | Logistic Regression (>75% conf)
Charge, refund, invoice, GST   | Billing Support            | Logistic Regression (>75% conf)
2FA, OTP, password reset, login| Account Support            | Logistic Regression (>75% conf)
Warranty, manual, inquiry      | General Inquiry            | Logistic Regression (>45% conf)
Unauthorized charge, hacked    | Admin_Fraud Escalation Desk| Rule-based keyword trigger override
Urgency & SLA Impact           | Priority (Low/Med/High/Crit| Balanced Logistic Regression
Complaint Text Similarity      | Top-3 Similar Solutions    | Sparse Cosine Similarity (Score %)
