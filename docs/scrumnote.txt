Introduction:
This is an AI-powered customer support ticket intelligence system designed for
consumer electronics support operations. It classifies ticket text, predicts
priority, and maps predictions to department queues using Natural Language
Processing and Machine Learning to support faster triage. The system includes
an AI Similar Historical Tickets recommendation feature that provides agents
with semantically similar historical resolutions using TF-IDF and cosine
similarity.

Objectives:
• Automate end-to-end customer support ticket triage and routing.
• Classify customer complaints into predefined categories using Logistic Regression.
• Predict the priority level (Low, Medium, High, Critical) for incoming tickets.
• Use TF-IDF and Logistic Regression for explainable ticket classification.
• Provide category and priority information to support staff during triage.
• Implement Role-Based Access Control (Customer, Agent, Admin) with session security.
• Reduce manual effort and improve customer satisfaction (CSAT) through faster support.
• Provide AI Similar Historical Tickets recommendations to assist agents with resolutions.

#Existing System:
Existing customer support operations rely on manual triage by human agents or rigid
rule-based pattern matchers that are slow, error-prone, and lack semantic understanding.

System                  | Description                                  | Limitation
------------------------+----------------------------------------------+--------------------------------------
Manual Support Triage   | Human agents read and route tickets manually.| Slow response time, high misrouting.
Rule-Based Regex Routers| Uses rigid keyword matching rules.           | Lacks semantic context; breaks easily.
Generic Helpdesk Forms  | Standard web forms without AI intelligence.  | No automated priority/category triage.
Keyword Search Systems  | Basic text matching for past resolutions.    | Low relevance, zero vector similarity.
Static Support Queues   | Monolithic queues without role isolation.    | No automated classification or priority prediction.


#Proposed System:
It proposes a cost-effective, explainable AI support ticket system that combines real-time
NLP categorization, machine learning priority prediction, automated multi-department
routing, and AI Similar Historical Tickets recommendations with customer, agent, and
administrator dashboards.

> AI Classification & Retrieval Mappings
Input Pattern / Issue          | Target Action / Department | AI Inference Method
-------------------------------+----------------------------+--------------------------------------
Ticket text                     | Technical/Billing/Account/ | Logistic Regression with
                               | General Inquiry department | confidence from predict_proba()
Ticket text                     | Low/Medium/High/Critical   | Logistic Regression with
                               | priority                   | confidence from predict_proba()
Low category confidence         | Manual-review indicator    | Threshold below 45%
Agent views ticket details     | Top-3 similar historical   | TF-IDF + Cosine Similarity
                               | tickets with similarity    | scores (demo: 92.4%, 86.8%, 79.5%)
Invalid input or model failure  | Safe default predictions   | Rule-based/default fallback

ticket_similar_matches | match_id (PK), ticketno (FK), similar_ticket_ref_id, similarity_score, similar_subject, similar_description, historical_resolution_hours, created_at | Stores historical similar ticket recommendations with TF-IDF cosine similarity scores for agent assistance
