COMPASSIQ — 5-STEP VIVA TEST SUITE
MCA Academic Mini-Project Evaluation Guide

This test suite provides a structured approach for demonstrating the CompassIQ
system during internal viva evaluation. Each step includes test inputs, expected
outputs, and edge-case verification.

PRE-REQUISITES
────────────────────────────────────────────────────────────────────────────
1. Python 3.8+ installed
2. Flask application running on http://127.0.0.1:5000
3. Database initialized with seed data
4. ML model artifacts present in models/ directory
5. Default demo accounts available (see docs/details.txt)

Command to start server:
  cd CompassIQ-AI
  python app.py

Expected startup output:
  [CompassIQ DB] Database schema already initialized. Ready.
  [CompassIQ ML] All 3 serialized model artifacts verified.
  [AI Engine] Successfully loaded TF-IDF vectorizer and classification models.
  [CompassIQ] Booting server on http://127.0.0.1:5000 (debug=True, use_reloader=False)...
  * Running on http://127.0.0.1:5000

TEST CASE 2.1: Technical Ticket Creation
────────────────────────────────────────────────────────────────────────────
Test Input:
  - Subject: "Server error 502"
  - Description: "Getting 502 Gateway Timeout when accessing API endpoint"

Procedure:
  1. Login as customer
  2. Navigate to "Create Ticket" section
  3. Fill subject and description
  4. Click "Submit Ticket" button

Expected Output:
  - Flash message: "Ticket TKT-XXXXXX created successfully! Routed to Technical team."
  - Ticket appears in "My Tickets" table
  - AI Predictions:
    - predicted_category: "Technical"
    - predicted_priority: "High"
    - assigned_department: "Technical"

AI Pipeline Explanation:
  1. Text Preprocessing: Lowercasing, stopword removal, lemmatization
  2. TF-IDF Vectorization: Convert text to numerical feature vector
  3. Category Prediction: Logistic Regression classifies as "Technical"
  4. Priority Prediction: Logistic Regression classifies as "High"
  5. Confidence Scoring: predict_proba() returns confidence > 45%

Database Verification:
  SELECT ticket_id, predicted_category, predicted_priority, assigned_department 
  FROM tickets WHERE subject='Server error 502';
  Expected: predicted_category='Technical', predicted_priority='High'

Status: [PASS] ✅
